# Hotel Booking Application

A simple starter project for practicing Git branching and merge conflict resolution.

## Features
- View available hotel rooms
- Search rooms by location
- Submit a room booking request (demo only; no backend/database)
- Responsive, plain HTML/CSS/JavaScript interface

## Run locally
Open `index.html` in your browser. No installation required.

## Git practical
Recommended branches:
- `main` — stable version
- `develop` — integration branch
- `feature/room-search` — room search work
- `feature/booking` — booking form work

See `GIT-PRACTICAL.md` for the step-by-step workflow and intentional merge-conflict exercise.
