# Hotel Booking Application

A responsive, front-end hotel booking demo built with HTML, CSS, and JavaScript.

## Features
- Browse sample room types and nightly prices
- Search sample rooms by location
- Validate optional search dates and required booking dates
- Prepare an on-page demo booking confirmation with guest details
- Responsive, plain HTML/CSS/JavaScript interface

## Run locally
Open `Hotel-Booking-Application/index.html` in your browser. No installation required.

Room search filters the sample room cards by their listed locations. Dates are
checked for a valid check-in/check-out range, but no live availability is
checked. Booking details are not sent to a server or stored, so this demo does
not make real reservations.
